# 🎓 Avalix.io

📌 **Avalix.io** é um projeto de site desenvolvido com HTML, CSS e JavaScript, criado para fins de estudo e prática de desenvolvimento web.  
O repositório contém diferentes versões de layout da página inicial, permitindo testar e comparar ideias de design e estrutura.

---

## 📝 Sobre o projeto

Este projeto tem como objetivo praticar:
- Estruturação de páginas com HTML
- Estilização com CSS
- Interações básicas com JavaScript
- Organização de arquivos de um projeto web

O repositório possui mais de uma versão da página principal (index.html, index2.html e index3.html), representando variações de layout e design.

## 🚀 Como executar o projeto

1. Clone o repositório:
   git clone https://github.com/nicolasinfo1/Avalix.io.git

2. Abra qualquer arquivo .html no navegador:
   index.html

Você também pode usar extensões como Live Server no VS Code para facilitar o desenvolvimento.
